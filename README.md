## ✦ Selected Creative Technology ✦

### ☾ [The Nocturne Machine](https://github.com/lazzaradani-oss/nocturne-machine)

**Experimental Interactive Web Experience**

A standalone interactive experiment exploring atmosphere, motion, light, cursor interaction, and playful human-computer interaction.

Built with **React, TypeScript, Vite, and CSS**, the experience combines a responsive luminous orb, procedural particle field, animated atmospheric layers, orbital rings, micro-interactions, and a reactive “WAKE” state.

**Focus:** Creative Frontend · Interaction Design · Motion · Visual Systems · React · TypeScript
